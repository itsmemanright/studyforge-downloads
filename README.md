# StudyForge release review assets

Owned-sample Android 16 emulator recordings for the a1 code18 foreground dataSync declaration. The network clip shows the actual user-started analysis, native OpenAI transmission consent, running notification and cancellation/checkpoint state. The optional local-import clip shows actual local processing of a developer-authored sample with an Android instrumentation picker fixture; it is not a recording of a human tester. No user materials, credentials, answers or account profile are included. These are developer QA demonstrations, not evidence of the Google Play 12-person/14-day test.
