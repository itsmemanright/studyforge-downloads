# 스터디포지 · StudyForge

교재·PPT·문제집·족보·녹취 자료로 나만의 학습실을 만드는 **Android 시제품 a1**입니다.

## 다운로드

**[최신 버전 다운로드 화면](https://github.com/itsmemanright/studyforge-downloads/releases/latest)**

- [a1 코드15 APK 바로 받기](https://github.com/itsmemanright/studyforge-downloads/releases/download/a1-code15/StudyForge-a1-code15.apk)
- [APK가 들어 있는 ZIP 받기](https://github.com/itsmemanright/studyforge-downloads/releases/download/a1-code15/StudyForge-a1-code15-APK.zip)

휴대폰에서 APK를 연 뒤 설치 또는 업데이트합니다. 기존 스터디포지 앱은 먼저 삭제하지 마세요.
다운로드 파일 이름이 `.bin`으로 바뀌면 ZIP을 받아 압축을 풀고 안의 `.apk`를 설치하세요.
Android 8 이상을 대상으로 하며, 이번 실제 검수는 Android 16 가상 휴대폰에서 진행했습니다.
아이폰용 설치 파일은 아직 제공하지 않습니다.

## 사용 방법

1. 앱을 설치합니다.
2. 첫 화면에 교재 PDF·사진·텍스트·족보·녹취·교수 강조 사항·시험 범위를 추가합니다. PPT는 PDF로 저장합니다.
3. ChatGPT를 연결하고 모델을 선택해 자료를 분석합니다.
4. 분석 완료 후 직접 문제 만들기를 누르고, 생성된 문제와 원본 근거를 보며 공부합니다.

현재 ChatGPT 플랜 사용 방식의 AI 분석·출제는 자격 있는 Plus·Pro 계정이 필요합니다.
자료와 풀이 기록은 기기에 보관됩니다. JSON 백업에는 원본 PDF·TXT 파일 자체가 포함되지 않습니다.

## a1 코드15

독립 2차 검수와 보기별 해설·원본 인용 검사를 유지하면서 중복 출력을 줄였습니다.
동일 12쪽 검수 자료와 GPT-6.1-Sol로 5문항 생성·재검수한 단일 실측은 약 4분 52초에서 1분 57초로 줄었습니다.
처리 시간은 자료·모델·서버 상태에 따라 달라집니다. Java 76개와 화면 검사 36개, 총 112개 검사를 통과했습니다.

다운로드 파일의 SHA-256은 각 릴리스의 `SHA256SUMS.txt`에서 확인할 수 있습니다.
