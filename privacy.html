문제별 Chat 해설

사용자가 해설 질문을 전송하면 해당 문제·보기·표시 정답·기존 해설·제공된 원문 인용과 이 문제의 대화 이력·추가 질문을 OpenAI로 전송합니다. 요청마다 앱의 전송 확인창을 표시하고 본인의 ChatGPT 구독 사용량을 사용합니다. 완료된 대화는 계정·문항 버전별로 기기에 암호화 보관하며, 대화 새로 시작 또는 앱 데이터 삭제로 지울 수 있습니다. 대화는 학습기록 JSON 백업에 포함하지 않습니다. 원 문제·정답·학습기록을 자동 변경하거나 Work에 메시지를 자동 전송하지 않습니다.

2. 외부 서비스로 전송되는 정보

기기에만 저장되는 자료와 AI 처리를 위해 외부로 전송되는 자료는 다릅니다. 앱의 AI 분석·문제 생성·검수·문항 수정·말로 화면 또는 기능 만들기는 인터넷 연결과 사용자가 승인한 ChatGPT 연결을 사용합니다.

  • OpenAI: 사용자가 해당 AI 작업을 시작하면 작업에 필요한 자료의 텍스트·PDF 또는 사진의 변환 이미지·분석 발췌·파일명·시험 범위·출제 요청·문항 또는 기능 코드 등이 OpenAI의 공개 API로 전송됩니다. 인증 토큰은 OpenAI 요청 인증에 사용됩니다. 전송한 자료와 요청은 분석·생성·검수에 사용하며, 결과를 받아 기기에 보관합니다. 앱은 사용자의 기존 ChatGPT 대화나 메모리를 읽는 권한을 요청하지 않습니다.
  • 네이버 클로바노트: 사용자가 전사본 공유 링크 가져오기를 요청하면 해당 공유 링크와 필요한 접속 정보가 네이버에 전달되고, 접근 가능한 전사본을 기기에 가져옵니다. 로그인·비밀번호 등 추가 권한이 필요하면 TXT 또는 붙여넣기를 안내합니다. ChatGPT 연결 토큰을 네이버로 보내지 않습니다. 가져온 전사본을 이후 AI 분석하면 OpenAI로 전송될 수 있습니다.
  • Google Forms · AI 콘텐츠 신고(코드18부터): 앱 안의 신고 화면에서 사용자가 직접 적고 제출한 신고 내용은 Google Forms를 통해 운영자에게 전달됩니다. 이메일 주소는 자동 수집하지 않고 Google 로그인을 요구하지 않습니다. 앱의 원본 자료·문항·풀이 기록·ChatGPT 연결 정보는 신고에 자동 첨부하지 않습니다. 답변을 원해 본문에 연락처를 적은 경우 해당 연락처는 신고 처리·회신에 사용합니다. 신고 결과를 다른 응답자에게 공개하지 않습니다. Google은 양식 서비스를 제공하는 과정의 접속 정보·쿠키 등을 자체 정책에 따라 처리할 수 있습니다. 신고를 제출하지 않으면 개발자에게 신고 내용이 전송되지 않습니다.
  • GitHub: 앱 다운로드 및 이 개인정보처리방침 웹페이지를 방문하면 GitHub가 웹서비스 제공을 위한 접속 정보를 처리할 수 있습니다. 앱의 개인 교재·풀이 기록이 다운로드 저장소에 자동으로 공개되는 기능은 없습니다.

외부 서비스는 요청을 처리하는 과정에서 IP 주소·접속 시각·기술적 정보를 자체 정책에 따라 처리할 수 있습니다. 해외 사업자의 서버에서 처리될 수 있으며, 각 사업자의 처리 국가·보관·삭제·이용 조건은 아래 정책과 사용 중인 계정 설정을 확인하세요. 앱의 요청은 store:false를 사용하지만, 이를 외부 서비스의 모든 로그가 즉시 삭제된다는 의미로 안내하지 않습니다.

3. 개발자 서버·광고·추적

현재 Android 시제품에는 학습 자료와 풀이 기록을 개발자의 별도 서버에 자동 동기화하는 기능이 없습니다. 개발자는 앱에 입력한 자료·토큰·풀이 기록을 원격으로 조회할 수 없습니다. 현재 앱에는 광고 SDK, 광고 ID 수집, 방문·행동 분석 SDK 또는 별도의 원격 오류 수집 SDK를 포함하지 않습니다. 개인정보를 판매하거나 광고 목적으로 제공하지 않습니다.

4. 보관 기간과 보호 조치

  • 연결 토큰, 설정·학습 기록과 분석 체크포인트는 Android Keystore의 키를 이용하여 앱 전용 기기 저장소에 암호화합니다. 가져온 원본 파일도 암호화하여 보관합니다.
  • 기기 저장 정보는 해당 기능을 계속 이용하는 동안 유지됩니다. 앱의 데이터 삭제 또는 앱 제거로 앱 전용 저장 정보를 지울 수 있습니다. 아래 5항의 기능별 삭제 범위를 확인하세요.
  • 원본을 처리·표시하기 위해 앱 전용 캐시에 일시적으로 복호화한 파일을 만들 수 있습니다. 정상 작업 종료 시 정리하고, 다음 앱 시작 시 남은 임시 파일을 정리합니다.
  • 외부 API 연결은 HTTPS를 사용합니다. 운영체제의 기본 앱 자동 백업은 비활성화되어 있습니다. 사용자가 직접 내보낸 백업·HTML 파일은 선택한 저장 위치의 보호·삭제 정책을 따릅니다.
  • 외부 서비스에 전송된 정보는 해당 서비스의 보관·삭제 정책을 따릅니다. 앱에서 로컬 정보를 지웠다고 외부 서비스가 보관한 정보까지 자동 삭제되는 것은 아닙니다.

5. 연결 해제·자료·학습 기록 삭제

앱은 개발자의 서버에 별도 이메일·비밀번호 회원 계정을 만들지 않고, 사용자가 이미 사용하는 ChatGPT 계정을 연결합니다. 삭제 범위는 다음과 같습니다.

  1. ChatGPT 연결: 앱의 로그아웃은 앱이 보관한 현재 연결 토큰을 비웁니다. 기기에 보관된 학습 자료와 다른 학습실을 모두 삭제하는 동작은 아닙니다. OpenAI에 부여한 앱 권한을 철회하려면 ChatGPT 설정의 보안·로그인 또는 연결 앱 관리에서 StudyForge를 연결 해제하세요. ChatGPT 계정 자체 삭제는 OpenAI에서 별도로 요청해야 합니다.
  2. 진행 초기화: 학습실의 진행 초기화는 현재 학습실의 답안·시도 이력·헷갈림 표시를 초기화합니다. 원본·문제·다른 학습실·이전 판까지 삭제하지 않습니다.
  3. 자료 목록에서 빼기: 자료의 × 버튼은 현재 작업공간의 자료 목록에서 제거합니다. 이전에 생성한 문제의 근거·분석 캐시·암호화된 원본의 모든 사본을 즉시 완전히 지우는 기능은 아닙니다.
  4. 앱이 보관한 정보를 모두 삭제: Android의 설정 → 앱 → 스터디포지 → 저장공간에서 데이터 삭제를 하거나 앱을 제거하세요. 기기 제조사에 따라 메뉴 이름은 다를 수 있습니다. 앱 전용 저장 정보가 삭제되며, 다시 사용할 때 연결·자료 추가가 필요합니다.
  5. 직접 내보낸 파일: 사용자가 저장·공유한 JSON 백업이나 학습 HTML은 앱 데이터 삭제와 별개입니다. 해당 파일이 있는 기기·클라우드·공유 위치에서 직접 삭제하세요. JSON 백업에는 학습 내용과 발췌·문항 등이 포함될 수 있지만, 가져온 원본 PDF·TXT 파일 자체를 모두 포함하는 백업은 아닙니다.
